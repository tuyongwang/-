## Project Overview

A Windows desktop application that creates a romantic popup animation — dialog boxes pop up one by one across the screen, forming a heart shape. Uses the user's actual desktop as background. Can generate a standalone .exe for distribution.

## Tech Stack

- Python 3.12+ with customtkinter, Pillow (PIL), tkinter
- PyInstaller for EXE packaging
- Windows-only (uses ctypes.windll for DPI awareness and screen metrics)

## Running

```bash
# Run the config app (lets user set name, messages, preview, generate EXE)
python love_app.py

# Run the standalone version (hardcoded name/messages, no config UI)
python LoveCards_standalone.py
```

## Building EXE

```bash
pyinstaller --onefile --windowed --icon=heart.ico --name LoveCards --clean --noconfirm _gen_target.py
```

The `_gen_target.py` file is auto-generated by `love_app.py`'s "Generate EXE" button — it embeds the user's name/messages into the standalone template.

## Architecture

- **love_app.py** — Main entry point. `ConfigWindow` (CTk) for user input, `FullscreenDisplay` (CTkToplevel) for the heart animation. Contains `STANDALONE_TEMPLATE` as a raw string literal used to generate the EXE source.
- **LoveCards_standalone.py** — Self-contained version with hardcoded NAME/MSGS. Used as reference; the actual EXE source is generated from the template in love_app.py.
- **make_win_dialog()** — Renders a single romantic-style dialog image (PIL). Gradient body, rose-gold border, decorative dots, centered text.
- **_heart_points()** — Generates heart curve coordinates using parametric equation: `x=16sin³(t)`, `y=13cos(t)-5cos(2t)-2cos(3t)-cos(4t)`.
- **_pre_render()** — Pre-renders all dialog images at startup for smooth animation.

## Key Customization Points

- `dw = 300` — dialog width
- `self.after(120, self._animate)` — animation interval (ms per dialog)
- `font_body = ImageFont.truetype(FONT_PATH, 18)` — message font size
- `t += 0.13` in `_heart_points()` — heart point density (smaller = more dialogs)
- `line_h = 28` — line height in dialog body

## Dependencies

Install before running:
```bash
pip install customtkinter Pillow pyinstaller
```

## Notes

- DPI awareness is set at script start via `ctypes.windll.shcore.SetProcessDpiAwareness(2)`
- Screen size uses `GetSystemMetrics` (not tkinter winfo) for accuracy across DPI settings
- Chinese font support requires Windows `msyh.ttc` or `simhei.ttf`
- The `libpng warning: iCCP: known incorrect sRGB profile` is harmless and can be ignored
- frontend-design skill is available at `.claude/skills/frontend-design/` for UI improvements
